# 桌面物体检测数据采集指南

## 实验目标

本项目使用 YOLOv8 完成桌面物体检测实验。

最终检测类别：

  类别编号   类别
  ---------- ----------
  0          mouse
  1          keyboard

## 数据采集要求

采集图片覆盖：

-   不同角度
-   不同距离
-   不同光照
-   不同背景
-   不同摆放位置

## 数据采集工具

工具：

`tools/capture_images.py`

支持：

-   摄像头预览
-   手动拍照
-   自动连拍
-   图片保存

## 使用方法

``` bash
python capture_images.py --class mouse
python capture_images.py --class keyboard
```

自动采集：

``` bash
python capture_images.py --class mouse --auto --interval 0.5
```

## 快捷键

  按键    功能
  ------- ------------
  空格    拍照
  a       自动连拍
  u       删除上一张
  q/ESC   退出
