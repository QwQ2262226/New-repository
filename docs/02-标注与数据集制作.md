# YOLOv8 自动标注与数据集制作流程

## 实验流程

    图片采集
     ↓
    YOLO自动预标注
     ↓
    labelImg人工修正
     ↓
    数据集划分
     ↓
    YOLO训练
     ↓
    Jetson部署

## 自动预标注

工具：

`tools/auto_label.py`

运行：

``` bash
python tools/auto_label.py --images dataset/raw --out dataset/labeled --classes mouse keyboard --model yolov8x.pt --conf 0.25
```

## 输出目录

    dataset/labeled/

    ├── images/
    ├── labels/
    ├── classes.txt
    ├── _preview/
    └── _review.csv

## 人工修正

使用 labelImg 检查：

-   漏框
-   错框
-   类别错误
-   框位置

格式选择：

    YOLO

## 数据集划分

使用：

`tools/split_dataset.py`

类别：

    0 mouse
    1 keyboard

## 模型训练

``` bash
yolo detect train model=yolov8n.pt data=dataset/data.yaml epochs=100 imgsz=640
```

## Jetson部署

文件：

    best_mouse_keyboard.pt
    tools/jetson_detect_ros2.py

实现：

-   摄像头读取
-   YOLO实时检测
-   检测框显示
-   ROS2结果发布
